Detailed Description

형태에 관한 모든 정보를 담는 구조체

Note
이 구조체는 변경 불가능한 상태로 사용된다. 인덱스는 모두 포인터로 변경되고, 후보 형태소 목록은 소유한 쪽(Kiwi::formCandidates 등)의 연속 배열을 가리킨다. kiwi::Kiwi 내에서 실제 형태소 분석 단계에 쓰인다.
